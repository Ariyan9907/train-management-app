# 🚂 Train Consist Management Application

A Java console-based application that demonstrates the implementation of Java Collections Framework, Stream API, Searching & Sorting Algorithms, Regular Expressions, Exception Handling, and Object-Oriented Programming concepts through a real-world Train Consist Management System.

---

# 📋 Project Overview

The Train Consist Management Application simulates the management of passenger and goods bogies in a train. It progressively implements 20 use cases, each introducing a different Java concept while maintaining a clean project structure and Git workflow.

# ✨ Features

## 🚆 Train Management

- Initialize train consist
- Manage passenger bogies
- Track unique bogie IDs
- Maintain ordered train consist
- Preserve insertion order
- Map bogie capacities
- Sort bogies
- Filter passenger bogies
- Group bogies by type
- Calculate total seating capacity
