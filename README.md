# 🚂 Train Consist Management Application

## 📌 Use Case 17 - Sort Bogie Names Using Arrays.sort()

### 📖 Description

This use case demonstrates the use of Java's built-in **Arrays.sort()** method to sort bogie names in alphabetical order. It simplifies sorting operations by utilizing the Java Arrays utility class instead of implementing a custom sorting algorithm.

---

## ✨ Features

- Store bogie names in an array
- Sort bogie names alphabetically
- Display the sorted list of bogie names
- Demonstrate Java's built-in sorting functionality

---

## ☕ Java Concepts Used

- Arrays
- Arrays.sort()
- Enhanced for-loop
- Java Arrays Utility Class

---

## 📂 Classes Modified

### TrainApplication.java

- Invokes the method to sort and display bogie names.

### TrainService.java

Implements the following method:

- `sortBogieNames()`

---

## ▶️ Expected Output

```text
========= Sorted Bogie Names =========

AC Chair
Coal Wagon
First Class
Petroleum Tank
Sleeper
```
