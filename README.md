# 🚂 Train Consist Management Application

## 📌 Use Case 16 - Bubble Sort Passenger Bogie Capacities

### 📖 Description

This use case demonstrates the implementation of the **Bubble Sort** algorithm to sort passenger bogie capacities in ascending order. It compares adjacent elements repeatedly and swaps them whenever they are in the wrong order until the entire array is sorted.

---

## ✨ Features

- Store passenger bogie capacities
- Sort capacities using the Bubble Sort algorithm
- Display sorted capacities
- Demonstrate manual sorting without built-in methods

---

## ☕ Java Concepts Used

- Bubble Sort
- Arrays
- Nested for-loops
- Conditional Statements
- Swapping Elements
- Object-Oriented Programming (OOP)

---

## 📂 Classes Modified

- Invokes the Bubble Sort operation.

### TrainService.java

Implements the following method:
